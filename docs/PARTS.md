# 部件说明文档

本文档对应场景中可点击的各部件，与 `js/partsData.js` 内容一致。

## 1. 塔架主钢结构桁架（towerFrame）

- **作用**：整机承重与导向框架，承受轿厢、卷扬机构自重及运行冲击载荷，并为轿厢提供垂直运行轨道。
- **工作原理**：由四根主立柱与水平杆、斜腹杆组成空间桁架结构。桁架将集中载荷分解为杆件轴向力，以最小的材料用量获得最大的抗弯、抗扭刚度；两侧导轨与轿厢导向轮配合，约束轿厢只能沿垂直方向运动。

## 2. 轿厢 / 载人座舱（gondola）

- **作用**：承载乘客沿塔架升降，是整机唯一的运动乘载部件。
- **工作原理**：轿厢通过导向轮组抱合塔架导轨运行。上升时由钢丝绳经卷扬机构牵引；下降时依靠自重自由落体，由底部磁缓冲制动系统与液压缓冲器分级减速、吸能，保证乘客安全着陆。

### 2.1 座椅（seat）

- **作用**：为乘客提供乘坐支撑，配合安全压杆将乘客固定于座舱内。
- **工作原理**：座椅按人体工学设计，背靠与座面分散人体载荷；自由落体阶段乘客处于近似失重状态，座椅与压杆共同承受减速阶段产生的过载（通常 2~4g）。

### 2.2 安全压杆（safetyBar）

- **作用**：运行前锁定，将乘客约束在座椅上，防止运行中抛离座位。
- **工作原理**：压杆绕铰点下压后由棘轮棘爪机构锁止，只能单向收紧；解锁需由液压/电控释放装置驱动，运行全程保持闭锁并带冗余锁止回路，满足游乐设施双重保护要求。

### 2.3 导向轮组（guideWheels）

- **作用**：连接轿厢与塔架导轨，承受侧向力并保证轿厢平稳垂直运行。
- **工作原理**：每组含承重轮与侧向导轮，分别从正面与侧面抱合导轨。滚轮采用聚氨酯包胶以降低噪音与冲击；多组轮系形成三点以上约束，消除轿厢俯仰与偏航自由度。

## 3. 顶部卷扬驱动机构

### 3.1 驱动电机（hoistMotor）

- **作用**：提供轿厢提升动力，是整机主驱动源。
- **工作原理**：三相异步电机（或变频电机）经减速器放大扭矩后驱动卷筒。变频器控制启动/停止加减速斜率，避免冲击；电机尾部带电磁失电制动器，断电时自动抱闸，防止轿厢意外下滑。

### 3.2 卷筒（drum）

- **作用**：收放钢丝绳，将电机旋转运动转换为轿厢直线升降运动。
- **工作原理**：卷筒表面加工螺旋绳槽，保证钢丝绳整齐排列、多层缠绕时不乱绳。卷筒直径与钢丝绳直径之比不小于规定值，以减小钢丝绳弯曲疲劳。

### 3.3 钢丝绳组（cables）

- **作用**：连接卷筒与轿厢，传递提升拉力。
- **工作原理**：采用多根独立钢丝绳并联冗余设计，单根破断拉力远大于额定载荷（安全系数 ≥ 10）。绳端以楔形绳套或压板固定，并配断绳检测开关，任一绳松弛即触发安全停机。

## 4. 锁止机构 · 塔顶卡位锁钩（lockHook）

- **作用**：轿厢到达塔顶后将其机械锁定，承担悬停期间全部载荷。
- **工作原理**：轿厢到位后，电磁/液压驱动的锁钩绕轴旋入轿厢吊耳卡位，形成纯机械锁止——悬停不依赖钢丝绳受力。释放时锁钩旋出，轿厢解锁进入自由落体。锁钩位置由接近开关双重确认。

## 5. 磁缓冲制动系统 · 永磁涡流刹车（magBrake）

- **作用**：在制动区对下落轿厢进行非接触式减速，是第一级（主）制动。
- **工作原理**：塔架两侧安装永磁体阵列，轿厢底部安装铜（铝）导电板。导电板随轿厢穿过磁场时感应出涡流，涡流与磁场相互作用产生与速度成正比的反向电磁阻尼力（楞次定律），速度越快制动力越大，无需供电、无机械磨损，且失效安全。

## 6. 液压缓冲器（hydraulic）

- **作用**：整机最后一道安全防线，吸收轿厢残余动能，防止刚性冲击。
- **工作原理**：轿厢触压活塞杆后，活塞挤压缸内液压油，油液经节流小孔高速流过，将动能转化为热能耗散。节流孔随行程渐变，使减速度近似恒定；缓冲结束后内置复位弹簧将活塞杆推回原位。

## 7. 底部基座（base）

- **作用**：承载整机全部静、动载荷并传递至地基，同时作为乘客上下平台。
- **工作原理**：钢筋混凝土基础通过地脚螺栓与塔架连接，按最不利工况（满载 + 制动冲击 + 风载）设计抗倾覆与抗压能力，并设减振垫层隔离运行振动。

## 8. 控制柜（controlCabinet）

- **作用**：整机电气控制核心，内含 PLC、变频器、安全回路与操作界面。
- **工作原理**：PLC 按预定程序控制提升、悬停、释放、制动全过程；安全回路串联门锁、压杆、断绳、超速等开关，任一异常立即切断动力并抱闸。变频器实现电机软启动与精确调速。

## 运转流程与制动能量链

```
上升（电机做功）→ 悬停（锁钩承载）→ 自由落体（势能→动能）
→ 磁刹减速（动能→涡流→热能）→ 液压缓冲（残余动能→热能）→ 复位
```

两级制动分工：磁缓冲制动承担绝大部分减速任务（非接触、无磨损、失效安全）；液压缓冲器作为最后一道防线吸收残余动能，二者构成冗余安全设计。
